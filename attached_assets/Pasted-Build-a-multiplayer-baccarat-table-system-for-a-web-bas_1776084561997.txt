Build a **multiplayer baccarat table system** for a web-based casino using a modern fullstack setup (Node.js backend + WebSocket real-time sync + React frontend).

The system must be **server-authoritative** (all game logic and RNG handled on backend).

---

# 🎯 CORE GOAL

Create a **real-time multiplayer baccarat table** where 1–6 players can sit, place bets, watch the same round, and receive payouts.

Include spectators, betting trends, and a GTA-style UI.

---

# 🧱 BACKEND REQUIREMENTS (Node.js)

## Game Engine

* Implement standard baccarat rules:

  * Player and Banker hands
  * Card values:

    * 2–9 = face value
    * 10/J/Q/K = 0
    * Ace = 1
  * Hand total = last digit of sum (mod 10)

* Third card rules:

  * Player draws if total <= 5
  * Banker follows full baccarat third-card rule table

## RNG (IMPORTANT)

* Use:

  * crypto.randomInt() for card draws
* Build a virtual shoe:

  * 6 or 8 decks
  * Shuffle server-side

## Round Flow

1. WAITING (players can sit)
2. BETTING (10–15 seconds)
3. LOCK (no more bets)
4. DEAL
5. RESULT
6. PAYOUT
7. RESET

Use a state machine for this.

## Betting System

Each player can bet:

* "player"
* "banker"
* "tie"

Track per round:

* totalPlayerBets
* totalBankerBets
* totalTieBets

## Payouts

* Player = 1:1
* Banker = 0.95:1 (5% commission)
* Tie = 8:1 (configurable to 9:1)

## Table Object

Each table should store:

* id
* players (max 6)
* spectators (unlimited)
* currentState
* bets
* history (last 20 results)
* minBet / maxBet

## WebSocket Events

Implement:

* joinTable
* leaveTable
* placeBet
* removeBet
* gameStateUpdate
* roundResult
* seatUpdate

Broadcast all updates to connected clients.
