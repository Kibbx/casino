Behaviour

activeNav string (e.g. "home", "poker") is stored in parent state. Clicking a nav item calls setActiveNav(item.id).
Each item's id is its label lowercased with hyphens (e.g. "table-games", "the-hub" items use "rewards", "challenges", "leaderboards").
When collapsed, section labels disappear entirely — only icons remain, centered in the 52px strip.
All icons are from lucide-react.
