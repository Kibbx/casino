5. QUEUE UPDATE LOOP

---

Run every few seconds:

function updateRaceQueue() {
const now = Date.now()

const readyRaces = allRaces.filter(r =>
r.status === 'QUEUED' &&
r.scheduledTime <= now + QUEUE_WINDOW &&
!r.isInQueue
)

for (const race of readyRaces) {
RaceQueue.push(race)
race.isInQueue = true
}

RaceQueue.sort((a, b) => a.scheduledTime - b.scheduledTime)
}

7. RACE LIFECYCLE

---

When race starts:

const now = Date.now()
race.delayMs = Math.max(0, now - race.scheduledTime)
race.actualStartTime = now

PHASES:

UPCOMING:

* betting open until bettingClosesAt

LOCKED:

* starts at bettingClosesAt
* lasts ~10 seconds

RUNNING:

* starts at actualStartTime
* lasts ~2m 15s

FINISHED:

* lasts ~15s

After finish:

* release horses
* clear reservations
* apply fatigue if winner
* ActiveRace = null
