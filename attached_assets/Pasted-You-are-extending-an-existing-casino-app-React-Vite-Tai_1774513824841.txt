## OWNER CUT LOGIC

Owner cut based on odds:

1–3 → 1%
4–8 → 2%
9–15 → 3%
16–22 → 4%
23–27 → 5%
28–30 → 6%

Store as decimal (0.01 → 0.06)

## OWNER PAYOUT LOGIC

When a horse wins:

1. Calculate total payout to players for that horse

2. Owner receives:
   ownerCut = totalPayout * horse.ownerCut

3. CONDITIONS:

* If owner bet on their own horse → NO payout
* If totalPayout < 5000 → NO payout
* Cap payout at 25,000

4. Add earnings:
   horse.totalEarnings += ownerCut

5. Add to player balance
