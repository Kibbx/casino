Build a full weekly Lottery feature for the Back Alley Bets casino website.

This should be a manual, claim-based lottery system. Players buy tickets for the current weekly draw, fill/mark their numbers, submit the tickets, then return after the Sunday draw to check and claim winning tickets.

Core Concept:
- Lottery draws happen weekly every Sunday.
- Default draw time: Sunday 9:00 PM EST.
- Default ticket close time: Sunday 8:55 PM EST.
- Banker can configure the draw time and close time.
- Each weekly draw has:
  - New tickets
  - New winning numbers
  - New weekly consolation pool
  - Its own locked prize amounts
- Tickets only last for the weekly draw they were purchased for.
- Tickets do not roll over.
- The jackpot can roll over.
- New week = new tickets, new numbers, same rolling jackpot unless it was hit.

Default Lottery Rules:
- Pick 4 numbers.
- Number range: 1–20.
- No duplicate numbers on the same ticket.
- Order does not matter.
- 4/4 any order = jackpot.
- 3/4 any order = weekly consolation prize.
- 2/4, 1/4, and 0/4 = no payout.

- The system checks:

  - Ticket sales are not closed.

- Buying tickets:
  - Deducts chips immediately.

- Player fills/marks numbers manually on each ticket.

- The player must manually submit tickets before ticket close.
- Submitted tickets become locked.

- Draft/unsubmitted tickets become void after ticket close and cannot win.

Ticket Submission Rules:

- No blank numbers.
- No numbers outside the allowed range.
- No duplicate numbers unless Banker setting allows duplicates.
- Tickets must be submitted before ticket close.
- Only submitted locked tickets are eligible to win.
- Draft, void, or unsubmitted tickets cannot win.
- Players can only see their own tickets.

Prize Split:
Default split from ticket sales:
- 20% House
- 70% Main Jackpot
- 10% Weekly Consolation Pool

Rules:
- Splits must always equal 100%.
- Banker can configure the split.
- Every ticket purchase immediately adds to the correct pools.
- Ticket sales continue adding to the pools until ticket close.
- At ticket close, the draw’s final jackpot and consolation amounts are locked.
- The draw uses only the locked prize amounts.

Weekly Draw Logic:
- At draw time, generate winning numbers server-side only.
- Staff cannot manually choose winning numbers.
- Banker may start/force the draw, but winning numbers must still be generated by secure server-side random logic.
- Each Sunday draw uses brand-new winning numbers.
- Only submitted locked tickets are checked.
- Check each submitted ticket against the winning numbers.
- Determine:
  - 4/4 jackpot tickets
  - 3/4 consolation tickets
  - losing tickets
  - void tickets
- Store matched count and result on each ticket.

Payout Logic:
- 4/4 winners split the main jackpot.
- 3/4 winners split only that week’s consolation pool.
- 3/4 payouts must not reduce the main jackpot.
- 2/4 or lower pays nothing.
- Prize splitting is based on winning tickets, not unique players.
- If one player owns multiple winning tickets, each winning ticket gets its own share.

Example:
- Jackpot: 12,000,000 chips
- 3 tickets hit 4/4
- Each jackpot ticket is worth 4,000,000 chips
- If one player owns 2 winning jackpot tickets, that player can claim 8,000,000 chips total.

Claim-Based System:
- Do not automatically pay winners immediately after the draw.
- After the draw, the backend should calculate winning tickets and payout amounts.
- Winning tickets should be marked as Unclaimed.
- Players must return to the Lottery page and click Claim Prize to receive winnings.
- Payouts are locked to the draw the ticket belongs to.
- A ticket from an old draw cannot claim the current jackpot.
- New ticket sales for the next draw must not change old payout amounts.
- Each ticket is tied to a specific draw ID.
- Each draw stores its own locked jackpot and consolation amounts.
- Claiming a prize pays from that completed draw’s reserved payout pool.
- Claiming last week’s prize must not reduce the current active jackpot.

Claim Window:
- Winning tickets are claimable for a Banker-configured claim window.
- Default claim window: until the next Sunday ticket close time.
- If a winning ticket is claimed before the deadline:
  - Pay the player from that draw’s reserved payout pool.
  - Mark the ticket as Claimed.
  - Log the payout.
- If a winning ticket is not claimed before the deadline:
  - Mark the ticket as Expired / Unclaimed.
  - Roll the unclaimed reserved prize share into the current active jackpot.
  - Log the rollover.
- If multiple jackpot tickets won and only some are claimed, only the unclaimed expired shares roll into the current jackpot.
- Example:
  - Jackpot: 12,000,000
  - 3 winning jackpot tickets
  - Each ticket claim is worth 4,000,000
  - 2 tickets are claimed
  - 1 ticket expires
  - Only 4,000,000 rolls into the current jackpot.

If Nobody Hits:
- If nobody hits 4/4:
  - Full main jackpot rolls into the next active draw.
- If nobody hits 3/4:
  - Unused weekly consolation pool rolls into the main jackpot for the next active draw.

Current Jackpot Handling:
- The current active jackpot should include:
  - Previous unhit jackpot rollovers
  - Current draw jackpot contributions from ticket sales
  - Expired unclaimed prize shares that have rolled in
- The current active jackpot should NOT include:
  - Reserved unclaimed prize shares from a completed draw that are still within the claim window
