## BACKEND LOGIC

1. HORSE CREATION

POST /api/admin/horses/create

Body:
{
name: string,
odds: number (1–30),
visualBase: string,
visualPattern: string,
visualFlair: string
}

On create:

* calculate weight = 1 / (odds + 1)
* normalize weights across all horses
* calculate ownerCut based on odds tier:

1–3 → 1%
4–8 → 2%
9–15 → 3%
16–22 → 4%
23–27 → 5%
28–30 → 6%

Save horse.

---

GET /api/admin/horses

Return:

* id
* name
* odds
* visualBase
* visualPattern
* visualFlair
* ownerId
* totalEarnings
