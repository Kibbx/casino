Build a complete Keno game for my website “Back Alley Bets” that also works inside FiveM NUI (tablet browser).

========================
COMPATIBILITY (VERY IMPORTANT)
==============================

* Must run as a normal website (hosted online)
* Must ALSO work inside FiveM NUI (CEF browser)
* Do NOT use heavy frameworks (no React/Vue)
* Use vanilla HTML, CSS, JavaScript
* Avoid anything that breaks in CEF:

  * No external popups
  * No unsupported APIs
* Keep performance lightweight

========================
CORE GAME
=========

* Grid: 80 numbers (1–80)
* Player selects 1–10 numbers (Picks)
* Draw: 20 random numbers per round
* Matches determine payout

PAYOUT TABLE

Use balanced multipliers (same structure as Stake but slightly nerfed for RP economy)

========================
BACKEND (WEB + FIVEM SAFE)
==========================

* All RNG and payouts handled server-side (Node.js or similar)
* Endpoint: POST /api/keno/play

Request:
{
bet: number,
picks: number[]
}

Response:
{
drawnNumbers: number[],
hits: number,
payout: number
}

========================
FIVEM SUPPORT
=============

* Detect if running inside FiveM:
  if (window.invokeNative) OR GetParentResourceName exists

* If in FiveM:
  Use NUI callback:
  fetch(`https://${GetParentResourceName()}/playKeno`, {...})

* If on website:
  Use normal API:
  fetch('/api/keno/play', {...})

* Same frontend must support BOTH automatically
