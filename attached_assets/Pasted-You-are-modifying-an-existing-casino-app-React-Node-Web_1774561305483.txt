## MOVEMENT SYSTEM (CORE LOGIC)

Each tick:

progressRatio = currentTick / TOTAL_TICKS

---

1. BASE SPEED

baseSpeed = speed / 100

---

2. ACCELERATION (START BOOST)

If progressRatio < 0.2:

accelBoost = (acceleration / 100) * (1 - progressRatio * 5)

Else:
accelBoost = 0

---

3. STAMINA (ENDURANCE)

If progressRatio > 0.7:

fatigue = (1 - stamina / 100) * (progressRatio - 0.7) * 2

Else:
fatigue = 0

---

4. SECOND WIND (STAMINA BONUS)

Chance to trigger once mid-race:

If not triggered AND random < stamina / 200:

secondWindBoost = +0.3 for next 2–3 seconds

---

5. LUCK (VARIANCE)

luckVariance = random(-0.3 to 0.3) * (luck / 100)

---

6. RARITY MODIFIER

rarityBoost = rarityModifier[horse.rarity]

---

7. FINAL MOVEMENT

delta =
(baseSpeed

* accelBoost
* secondWindBoost
* luckVariance

- fatigue)

* rarityBoost

Clamp delta to >= 0

---

8. UPDATE POSITION

position += delta

Clamp max = 100
