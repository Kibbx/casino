# Dynamic Resolution & Responsive Requirements

The application must be fully responsive and dynamically adapt to any screen size.

Support:

* 3440px Ultrawide
* 2560px Desktop
* 1920px Desktop
* 1600px Laptop
* 1440px Laptop
* 1366px Laptop
* 1280px Desktop
* 1024px Tablet Landscape
* 768px Tablet
* 480px Mobile
* 390px Mobile
* 375px Mobile

Layout behavior:

### Large Screens (1600px+)

* Fixed left navigation
* Wide two-column layout
* Lottery card on left
* Tickets card on right
* Maximum content width of 1800px
* Proper spacing to avoid excessive empty space

### Desktop (1280px–1599px)

* Two-column layout maintained
* Proportional scaling
* Cards remain side-by-side

### Tablet (768px–1279px)

* Sidebar collapses into icon-only mode
* Main content stacks intelligently
* Lottery card displayed first
* Tickets card displayed second

### Mobile (<768px)

* Sidebar becomes slide-out drawer
* Header condenses
* Search bar becomes collapsible
* Content becomes single-column
* Tables become mobile-friendly cards
* Buttons remain touch-friendly
* Maintain premium visual appearance

No horizontal scrolling.

No fixed widths.

Use fluid layouts with:

* CSS Grid
* Flexbox
* clamp()
* minmax()
* responsive Tailwind utilities
