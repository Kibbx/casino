PAYLINE EVALUATION LOGIC:

For each payline:
1. Read exactly 5 symbols using the payline coordinates.
2. Start from reel 1 only.
3. Move left to right.
4. Determine the target paying symbol:
   - If reel 1 is a normal symbol, that is the target symbol.
   - If reel 1 is Wild, look right until the first connected non-Wild normal symbol.
   - If the first connected non-Wild symbol is Scatter, no normal line win.
   - If the first 3+ connected symbols are all Wild, pay Wild.
5. Count the connected streak:
   - normal target symbol counts
   - Wild counts as the target symbol
   - any other normal symbol breaks the streak
   - Scatter breaks the streak
6. Stop counting immediately when the streak breaks.
7. Pay only if matchCount is 3, 4, or 5.
8. Only include connected positions in the winning positions array.
9. Do not include symbols after the break.
10. Do not scan later reels for another win after the chain breaks.
