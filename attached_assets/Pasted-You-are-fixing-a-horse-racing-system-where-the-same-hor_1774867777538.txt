The previous balancing attempt failed.

## CRITICAL FIXES (MANDATORY)

1. NORMALIZE ALL HORSES BEFORE RACE

Before the race starts:

Find the average stats of the 6 horses in the race.

For each horse:

normalizedStat = stat / averageStatOfRace

This ensures:

* Horses are compared RELATIVE to each race
* No horse has overwhelming advantage

---

2. HARD CAP STAT ADVANTAGE

Clamp stat influence:

statEffect = Math.pow(normalizedStat, 0.6)

statEffect = clamp(statEffect, 0.85, 1.15)

This means:

* Stats can only give ±15% advantage MAX

Replace old variance with:

variance = randomBetween(-0.15, +0.15)

Events MUST trigger during race loop, not once.

for (tick = 0 → raceDuration):
update each horse position

- stat influence (small)

- active events
- pack compression

If horse is leading:

leaderPenalty = 0.02 → 0.05 (2–5%)

apply boost:

recentWins = wins in last N races

penalty:

streakPenalty = recentWins * 0.05

finalPerformance -= streakPenalty

8. REDUCE STAT IMPORTANCE FURTHER

Final rule:

Stats should only contribute ~15–20% of total outcome.
