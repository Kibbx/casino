WIN LOGIC RULES:

Valid wins:
- Must start from reel 1.
- Must run left to right.
- Must be consecutive.
- Must be matching symbol, with Wild substitution allowed.
- Must be 3, 4, or 5 of a kind.
- Scatter is excluded from normal line wins.

Invalid wins:
- Mixed symbols do not pay.
- Gaps do not pay.
- Right-to-left does not pay.
- Symbols on reels 1, 3, and 5 do not pay if reel 2 breaks the chain.
- Random symbols on the same line do not pay.
- Scatter does not count as a normal line symbol.

WILD LOGIC:

Wild substitutes for:
- Bag
- Crosses
- Diamonds
- Flask
- Gun
- Hat
- Hearts
- Spades

Wild does not substitute for Scatter.

If the line starts with Wild:
- Look ahead to the first non-Wild, non-Scatter symbol in the consecutive streak.
- Use that symbol as the paying symbol.
- If all matched symbols are Wilds, pay Wild.

Examples:

Wild, Spades, Spades, Bag, Bag
= 3x Spades if the first 3 can be counted.

Wild, Wild, Gun, Hat, Bag
= 3x Gun.

Wild, Wild, Wild, Bag, Bag
= 3x Wild OR best valid payout, depending on existing game rule.
Prefer paying Wild if the first 3 are all Wilds.

Wild, Scatter, Wild
= no normal line win because Scatter breaks the line.
