Jackpots must:

JACKPOT LOGIC (IMPORTANT):
Use a “must-hit range” system, NOT pure random.

Each jackpot has:
- Min value (starting point)
- Max value (must-hit cap)

Example:
- Grand: min 2,000,000 / max 5,000,000

On each spin:
- Calculate probability based on current jackpot value
- The closer to max → higher chance to hit
- If RNG passes threshold → jackpot hits
- Reset jackpot to min after win
