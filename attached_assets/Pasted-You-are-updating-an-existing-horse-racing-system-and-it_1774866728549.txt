## PART 1 — RACE BALANCE FIX

CURRENT PROBLEM:

* Highest stat horse wins almost every race
* System is too deterministic

We must convert it into a probabilistic system.

---

1. APPLY DIMINISHING RETURNS TO STATS

Replace linear stat scaling with:

statEffect = Math.pow(stat / 100, 0.65)

Apply to:

* speedStat
* staminaStat
* accelerationStat

---

2. LIMIT TOTAL STAT IMPACT

Stats should only contribute ~20–25% total.

Example:

speedContribution = statEffect * 0.25

Do NOT exceed this cap.

---

3. ADD RACE VARIANCE

Each horse gets per-race randomness:

const variance = randomBetween(-0.08, 0.08)

Apply:

finalPerformance *= (1 + variance)

---

4. IMPLEMENT 3 RACE PHASES

Split race into:

START (0–20%)

* Use accelerationStat
* Apply burst bonus

MID (20–80%)

* Use speedStat
* Add slight oscillation from luck

FINAL (80–100%)

* Use staminaStat
* Allow “second wind” chance

---

5. ADD EVENT SYSTEM

Each horse can trigger random events.

Chance:

eventChance = 5% + (luckStat * 0.05%)

Events:

* clean_stride → +5% speed (short duration)
* stumble → -6% speed (short duration)
* second_wind → +10% speed (final phase only)
* lucky_surge → random burst

Events must:

* Be temporary
* Stack with performance
* Trigger during race loop

---

6. ADD PACK COMPRESSION

Prevent runaway leaders.

If ahead:

* Apply -1% to -3% drag

If behind:

* Apply +1% to +3% boost

---

7. ADD WINNER FATIGUE

Track wins per horse:

fatigueStacks += 1 per win

fatiguePenalty = fatigueStacks * 0.02

Apply:

finalPerformance -= fatiguePenalty

Reset after:

* A loss OR
* Configurable number of races

---

8. LUCK RULE

Luck must NOT increase base speed.

Luck ONLY:

* Increases event chance
* Slightly increases variance range:

varianceRange = 0.08 + (luckStat * 0.0005)

---

9. FINAL PERFORMANCE MODEL

base = 1.0

speedFactor = Math.pow(speedStat / 100, 0.65) * 0.25

variance = randomBetween(-varianceRange, varianceRange)

eventBoost = sum of active event effects

fatiguePenalty = fatigueStacks * 0.02

finalPerformance =
base

* speedFactor
* eventBoost
* variance

- fatiguePenalty

---

10. TARGET OUTCOME

* Best horse wins ~20–30% (NOT 100%)
* Mid horses win sometimes
* Low horses rarely win but can
