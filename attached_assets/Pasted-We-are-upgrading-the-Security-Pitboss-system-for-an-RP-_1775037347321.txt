We are upgrading the Security / Pitboss system for an RP casino.

GOAL:

1. Flags must be editable in place (no delete/re-add)
2. Security must be able to attach photos to players for visual identification (blacklist system)

This should feel like a real casino watchlist system — fast, visual, and clean.

---

1. FLAG SYSTEM FIX (EDITABLE FLAGS)

---

Replace the current flag system with a SINGLE editable flag per user.

User model fields:

* isFlagged (boolean)
* flagSeverity (enum: low, medium, high)
* flagReason (string)
* flaggedAt (timestamp)
* flaggedBy (userId)

IMPORTANT:

* DO NOT create/delete flag records anymore
* A user always has ONE active flag (or none)

---

2. UPDATE FLAG IN PLACE (CORE FIX)

---

Create/update endpoint:

PATCH /admin/users/:id/flag

Body:
{
isFlagged: true,
flagSeverity: "high",
flagReason: "Chip scammer / suspicious deposits"
}

Behavior:

* If isFlagged = true → update fields directly
* If isFlagged = false → clear all flag fields
* NO deleting + recreating flags

---

3. UI FIX (SECURITY PANEL)

---

When viewing a player:

IF NOT FLAGGED:
→ Show button: [ Add Flag ]

IF FLAGGED:
→ Show editable inputs:

* Severity dropdown (low / medium / high)
* Reason text input

Buttons:
[ Save Changes ]
[ Remove Flag ]

Changes update instantly (no page reload)

---

4. OPTIONAL FLAG HISTORY (RECOMMENDED)

---

Create flagHistory:

* userId
* changedBy
* oldSeverity
* newSeverity
* oldReason
* newReason
* timestamp

---

5. SECURITY PHOTO SYSTEM (CORE FEATURE)

---

Extend User model:

* securityPhotos (array of image URLs)
* primaryPhotoUrl (string)
* securityNotes (text, internal only)

---

6. PHOTO MANAGEMENT

---

Security roles (security, pitboss, admin) can:

* Upload photos
* Add via URL (fallback)
* Delete photos
* Set a PRIMARY photo

Use cases:

* Back room photos
* Screenshots from RP
* Different outfits / disguises

---

Only roles:

Can:

* Add/edit/remove flags
* Upload/delete photos

Players cannot see any of this data

---

---

* Store image URLs (use existing upload system if available)

---

FINAL RESULT:

Security can:

* Edit flags instantly (no delete/re-add)
* Attach faces to players
* Recognize problem players immediately
* Run a real casino-style watchlist system
